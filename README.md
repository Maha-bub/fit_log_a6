# FitLog

**FitLog** is a modern fitness and workout tracking frontend application designed to help users explore exercises and manage their workout plans.

### Technologies

* Next.js & React
* TypeScript
* Tailwind CSS & DaisyUI
* React Icons
* React Toastify ect.

### Key Features

* Exercise sorting and filtering
* Add & remove workout plans
* Interactive and responsive UI
* Toast notifications
* TypeScript-based application
